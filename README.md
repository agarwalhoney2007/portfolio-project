# Honey Nirmal Agarwal — Personal Resume Website

A responsive, single-page personal profile website built with HTML5 and CSS3.

## Files
- `index.html` — page structure and profile content
- `style.css` — visual design, layout and responsive rules

## Run locally
Keep `index.html` and `style.css` in the same folder, then open `index.html` in a browser.

## Publish with GitHub Pages
Upload the contents of this folder to a public GitHub repository, keeping `index.html` in the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Notes
The page content is based on the supplied CV. No employment history, dates, grades beyond those stated, or additional credentials have been invented. The public profile does not display a photograph or full residential address.
